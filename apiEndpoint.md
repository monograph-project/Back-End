### Shared Blog Shapes

#### `ArticleBlockRequest`

```json
{
  "type": "TEXT",
  "order": 0,
  "data": {
    "text": "Paragraph text"
  }
}
```

Allowed `type` values:

- `TEXT`
- `HEADING`
- `IMAGE`
- `VIDEO`
- `CODE`
- `QUOTE`
- `EMBED`
- `DIVIDER`

Important `data` rules from validator:

- `TEXT`: `text`
- `HEADING`: `text`, `level`
- `IMAGE`: `fileId`, `url`, `alt`
- `VIDEO`: `fileId`, `url`
- `CODE`: `code`, `language`
- `QUOTE`: `text`
- `EMBED`: `provider`, `url`
- `DIVIDER`: no required fields

#### `CreateArticleRequest`

```json
{
  "title": "How to use microservices in university systems",
```
